# Pixel Art Editor

A vanilla JavaScript pixel art editor built with HTML5 Canvas.

## Features

- Drawing tools (pencil, line, rectangle, circle, etc....)
- Color picker
- Undo/Redo support
- Zoom controls
- Save/Load images
- Fill tool
- Eraser

## How to Use

1. Open `index.html` in a browser
2. Select a tool from the dropdown
3. Pick a color
4. Click and drag on the canvas to draw
