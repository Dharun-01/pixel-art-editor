# Pixel Art Editor

A vanilla JavaScript pixel art editor built with HTML5 Canvas.

## Features

- Drawing tools (pencil, line, rectangle, circle)
- Color picker
- Undo/Redo support
- Zoom controls
- Save/Load images
- Fill tool
- Eraser

## How to Use

1. Open `index.html` in a browser
2. Select a tool from the dropdown
3. Pick a color
4. Click and drag on the canvas to draw

## Keyboard Shortcuts

- `d` - Draw tool
- `f` - Fill tool
- `r` - Rectangle tool
- `c` - Circle tool
- `l` - Line tool
- `p` - Color picker
- `Ctrl/Cmd + Z` - Undo
- `Ctrl/Cmd + Y` - Redo
